# ad-pipeline-independent

An independent, clean-room implementation of an AI video ad generation pipeline.
The core scripts (`extract_product_views.py` / `ad_director.py` /
`render_pipeline.py` / `finalize_ad.py`) were designed and written from scratch,
without referencing or copying any existing codebase's source. `ad_tracker.py`,
`lib/story_reel/`, and `scripts/run_full_pipeline.sh` are carried over from my
own pre-existing original files (the latter had its path references adjusted
to fit this repo's layout).

## Directory structure

```
ad-pipeline-independent/
├── README.md
├── requirements.txt
├── config/settings.example.json   # copy to settings.json and fill in real secrets (gitignored)
├── scripts/
│   ├── extract_product_views.py   # product view photos -> assets/<brand>/<view>.png
│   ├── ad_director.py             # LLM-generated storyboard -> workflows/<title>.json
│   ├── render_pipeline.py         # spec -> silent rendered video (backend picked by animate_backend)
│   ├── finalize_ad.py             # silent video -> narration/subtitles/music -> outputs/<title>_full.mp4
│   ├── ad_tracker.py              # publication tracking & performance (CSV/xlsx)
│   └── run_full_pipeline.sh       # one-shot script chaining all the steps above
├── lib/story_reel/                # rendering dependency abstraction layer (stub, reused by render_pipeline.py)
├── workflows/                     # spec JSON files generated by ad_director.py
├── outputs/                       # rendered/final videos & tracking tables (large files gitignored)
└── tests/
```

## Pipeline

1. `extract_product_views.py` — sorts raw product photos by angle into
   `assets/<brand>/<view>.png`.
2. `ad_director.py` — calls an LLM to turn the product views (+ optional
   brief) into a storyboard spec JSON, written to `workflows/<title>.json`.
   The spec **must always** include an `animate_backend` field
   (`wan_flf` = paid cloud render, `interp` = free local placeholder/interpolation
   render).
3. `render_pipeline.py` — reads the spec and picks a render backend based on
   `animate_backend`, producing a silent video at `outputs/<title>_silent.mp4`.
   Both backends are implemented against the `lib/story_reel/` abstraction, so
   this script has no hard dependency on any specific local render environment.
4. `finalize_ad.py` — adds narration (TTS), subtitles, and background music to
   the silent video, producing the final ad at `outputs/<title>_full.mp4`.
5. `ad_tracker.py register` — registers the finished ad; use `publish` /
   `metrics` / `report` / `export` afterward to track multi-platform
   performance.

Run everything end-to-end:

```bash
./scripts/run_full_pipeline.sh <raw_photo.png> <product_name> ["optional brief"]
```

## Current status

All five pipeline scripts are implemented and have been exercised against
real product photos and real API calls:

- `extract_product_views.py`, `ad_director.py` (including scene-image
  generation), `render_pipeline.py` (`interp` / `wan_flf` / `wan_flf_local`
  backends), and `finalize_ad.py` (narration, subtitles, mixing).
- `ad_tracker.py`, `lib/story_reel/*`, and `scripts/run_full_pipeline.sh`
  were already complete, carried over as-is.

Known gaps:

- `wan_flf_local` (local ComfyUI backend) is implemented but hasn't been
  tested end-to-end — no GPU/ComfyUI environment has been available yet.
- Automatic background-music generation isn't implemented: OpenRouter's
  only music-generation models (Google Lyria 3) return a region
  restriction on this account. `finalize_ad.py --music` still accepts a
  manually supplied track.

## Setup

```bash
pip install -r requirements.txt
cp config/settings.example.json config/settings.json  # then fill in real secrets
```

Requires Python 3.10+ and `ffmpeg` on `PATH`.
